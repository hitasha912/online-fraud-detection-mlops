# Online Fraud Transaction Detection – End-to-End MLOps

An end-to-end machine learning and MLOps project for detecting fraudulent online transactions using **Python, Scikit-learn, FastAPI, GitHub Actions, Azure Machine Learning, and MLflow**.

---

## 1. Project Overview

This project develops an end-to-end fraud detection system, starting from transaction data preprocessing and model development and extending to API deployment, automated testing, Azure Machine Learning, MLflow tracking, model registration, and cloud deployment.
